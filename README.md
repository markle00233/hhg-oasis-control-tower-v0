# HHG Oasis — Control Tower Lite V0 demo

Standalone clickable UI prototype based on the transitional management control system brief.

## Open
Open `index.html` in Chrome/Edge.

## Included screens
- Control Tower / executive dashboard
- Projects
- Tasks
- Decision Queue
- Staff app / My Tasks
- Report Issue / QR flow
- System Blueprint
- Priority Gate: “New Task = Replace Task” demo

## Important
All financial and operational figures in this prototype are illustrative demo data, not actual HHG Oasis records.
